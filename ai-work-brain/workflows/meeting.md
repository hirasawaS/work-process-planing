# Meeting Workflow

## Goal

Turn a meeting into state changes and executable work.

## Flow

```
Meeting transcript
↓
Facts
↓
Decisions
↓
Questions
↓
Changed assumptions
↓
Actions
↓
Open-loop updates
↓
State update
↓
Required outputs
↓
Human review
```

## Required extraction

- What was decided?
- What was explicitly not decided?
- What changed from the previous state?
- Which assumptions changed?
- Who owns each action?
- What is blocked?
- What is on the critical path?
- Which stakeholders need follow-up?
- Which documents need updating?
- Which Slack communications are required?

The agent should produce draft outputs rather than silently send communications.
