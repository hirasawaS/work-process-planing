# Output Review Workflow

Every meaningful AI-generated work product should pass through review.

## Flow

```
Draft
↓
Review Agent
↓
Human Review
↓
Correction
↓
Revision
↓
Feedback extraction
↓
Learning decision
↓
Approved output
```

## Review questions

1. Is the output consistent with Project Context?
2. Did the agent invent any facts?
3. Are inference and fact separated?
4. Did it miss an important stakeholder?
5. Did it miss a dependency?
6. Is the granularity appropriate?
7. Does the output actually move the work forward?
8. Is the proposed next action clear?
9. Does it reflect the user's established working rules?
10. Is any feedback generalizable?

## Approval boundary

Human approval is required before consequential external actions unless an explicit automation policy grants permission.
