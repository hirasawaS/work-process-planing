# Workflow: 実行

## 目的

小さく、レビューしやすい単位で進め、現実と計画がズレたらすぐに調整する。

## フロー

計画
→ 実行
→ ラフなアウトプット
→ レビュー
→ 継続 / 再計画

## 手順

### 1. 計画

Work Plan があり、サブゴールと成果物が明確な状態で始める。

### 2. 実行

子タスクを管理しやすい粒度で進める。

### 3. ラフなアウトプット

レビューに使える最初の一歩や部分成果を作る。

### 4. レビュー

ラフなアウトプットを計画と現実の両方に照らして確認する。

### 5. 継続 / 再計画

仕事が続けられるなら続ける。前提が変わったなら計画を更新して再開する。

## 原則

実行は硬いものではなく、反復的なものだ。
