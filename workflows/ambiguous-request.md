# Workflow: 曖昧な依頼

## 目的

依頼が曖昧なときは、すぐに実行に入らない。
まず仕事の定義を明確にしてから進む。

## フロー

依頼
→ 明確化
→ 仕事の定義
→ 合意

## 手順

### 1. 依頼を受け取る

最初の依頼を、平易な言葉で受け止める。

### 2. 明確化する

不足している事実、仮定、制約を洗い出す。

次のような問いを投げる。

- 何を達成したいのか
- 何をもって成功とするのか
- 誰が受け手なのか
- どんな制約があるのか
- 何がまだ不明なのか

### 3. 仕事の定義をする

次の観点で仕事を定義する。

- 目的
- 背景
- 期待結果
- 成果物
- 制約
- 関係者
- 未確定事項

### 4. 合意する

実行前に定義を確認する。

ここで合意しておくことで、人間と AI が同じ前提で進められる。
