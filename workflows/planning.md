# Workflow: 計画づくり

## 目的

仕事の定義を、実行可能な計画に落とし込む。

## フロー

仕事の定義
→ サブゴール
→ 成果物
→ 入力
→ 依存関係
→ Work Plan
→ 計画レビュー

## 手順

### 1. 仕事の定義

目的、成果、制約、関係者を明確にする。

### 2. サブゴール

仕事を意味のある単位に分割する。

### 3. 成果物

各段階で何を出すのかを決める。

### 4. 入力

何の情報、アクセス、判断が必要かを整理する。

### 5. 依存関係

前提条件、順番、ボトルネックを把握する。

### 6. Work Plan

ただのタスクリストではなく、仕事を成立させる設計として書く。

### 7. 計画レビュー

この計画で現状の情報と制約の中で仕事が成立するかを見直す。

## レビューの問い

「この計画で、現時点の情報と制約の中で仕事は成立するか？」
