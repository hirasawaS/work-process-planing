# Checklist: 提出前チェック

最終提出または引き渡し前に使う。

## 成果物の品質

- [ ] 成果物が定義された目的に合っている
- [ ] 成果物が期待結果に対して十分に対応している
- [ ] 対象読者にとって十分に理解できる状態になっている

## 仮定と根拠

- [ ] 仮定が明示されている
- [ ] 重要な主張に根拠や入力がある
- [ ] 解決していない疑問が明確に残っている

## レビューと修正

- [ ] 成果物をドラフトとして一度確認している
- [ ] 見落としやリスクを確認している
- [ ] 実行中に計画が変わっていれば更新している

## 提出準備

- [ ] 追加の背景なしで成果物を理解できる
- [ ] 対象者や関係者が明確である
- [ ] 提出後に次に何をすべきか明確である

## 最終確認

- [ ] 成果物が元の意図だけでなく、現実に沿っている
- [ ] 重要な不確実性が開示されている
- [ ] 最終判断は AI ではなく、オーナーが持つ
