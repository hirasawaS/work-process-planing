# Checklist: 実行前チェック

実行を始める前に使う。

## 目的と範囲

- [ ] 仕事の目的が明確である
- [ ] 期待結果が定義されている
- [ ] 成果物が理解されている
- [ ] 関連する制約が把握されている

## 定義チェック

- [ ] 実行前に仕事が定義されている
- [ ] 関係者が特定されている
- [ ] 未確定事項が見えている
- [ ] 不足情報を黙って仮定で埋めていない

## 範囲とリスク

- [ ] 今の目的に対して、仕事が過大になっていない
- [ ] 依存関係が見えている
- [ ] リスクやブロッカーが明示されている

## 実行準備

- [ ] 次のアクションが明確である
- [ ] タスクがレビューしやすい粒度である
- [ ] 次の段階で意味のある成果物がある

## AI の使い方

- [ ] AI は構造化、レビュー、分解のために使っている
- [ ] 最終判断は人間が持っている
