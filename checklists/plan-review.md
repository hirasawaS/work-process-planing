# Checklist: 計画レビュー

Work Plan が妥当かを見直すときに使う。

## 仕事の定義

- [ ] 仕事の目的が明確である
- [ ] 成功条件が明示されている
- [ ] 成果物が明確である
- [ ] 制約が反映されている

## サブゴールと成果物

- [ ] 仕事が意味のあるサブゴールに分解されている
- [ ] 各サブゴールに具体的な成果物がある
- [ ] 成果物が最終結果につながっている

## 入力と不足情報

- [ ] 必要な入力が特定されている
- [ ] 不足情報が見えていて、仮定に隠れていない
- [ ] 不足情報を解消する計画がある

## 依存関係とリスク

- [ ] 重要な依存関係がわかっている
- [ ] 実行順序が妥当である
- [ ] リスクやブロッカーが明示されている
- [ ] 仮定が崩れたときの再計画パスがある

## 実行の質

- [ ] タスク粒度が実行可能である
- [ ] 各ステップに明確な入力と成果物がある
- [ ] 次の一手が推測なしで理解できる

## 最終チェック

- [ ] 計画はタスクの羅列ではなく、仕事を支える設計になっている
- [ ] 計画がレビュー可能である
- [ ] 現実が変わったときに、罪悪感なく修正できる
